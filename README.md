# ELM vs SVM: Machine Learning Model Comparison

A comparative machine learning project that studies Extreme Learning Machine (ELM) and Support Vector Machine (SVM) models across the datasets configured in the project. It demonstrates model preparation, training, and performance comparison.

- **Model Comparison:** Examines ELM and SVM using the implemented experiments.
- **Datasets:** Includes experiments involving datasets such as Iris, rice, and concrete-strength categories, as configured in the project.
- **Preprocessing:** Applies the data preparation and feature scaling required by the models.
- **Training and Testing:** Evaluates models using the experimental splits implemented in the project.
- **Evaluation:** Compares model performance using the available classification metrics.

## Technologies Used

Python · Scikit-learn · NumPy · Pandas · Extreme Learning Machine · Support Vector Machine

## Project Workflow

1. Load the selected dataset.
2. Prepare features and target labels.
3. Apply preprocessing and scaling where required.
4. Train the ELM and SVM models.
5. Evaluate and compare the model outputs.
